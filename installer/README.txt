====================================================
 Blenda 4D 0.1.27 - One-Click Installer (Win + Mac)
 Blenda 4D 0.1.27 一键安装包（Windows + macOS 通用）
====================================================

WHAT IS THIS / 这是什么
----------------------------------------------------
Blenda 4D is a free, open-source motion-design layout and
workflow for Blender (GPL-3.0). This package installs it
into every Blender 5.2 or newer on your computer, and
enables it - no manual steps needed.

Blenda 4D 是免费开源的 Blender 动态设计布局与工作流
插件（GPL-3.0 协议）。本安装包会把它装进你电脑里
所有 Blender 5.2 及以上版本并自动启用，全程无需
手动操作。

INSTALL / 安装
----------------------------------------------------
macOS:
  Double-click  "Install Blenda4D (Mac).command"
  双击 "Install Blenda4D (Mac).command"
  If macOS blocks it the first time: right-click the file,
  choose "Open", then "Open" again.
  如首次被系统拦截：右键点文件 → 打开 → 再点“打开”。

Windows:
  Double-click  "Install Blenda4D (Windows).bat"
  双击 "Install Blenda4D (Windows).bat"

Then restart Blender - it opens in the Blenda 4D layout.
装完重启 Blender，即自动进入 Blenda 4D 布局。
Top-right "Blenda 4D | Blender" switches back and forth.
界面右上角 “Blenda 4D | Blender” 可随时切换回原生界面。

UNINSTALL / 卸载
----------------------------------------------------
Double-click the matching "Uninstall Blenda4D" file.
双击对应的 "Uninstall Blenda4D" 文件即可。
Your own layouts, files and other add-ons are untouched.
不会动你自己的布局、文件和其他插件。

NOTES / 说明
----------------------------------------------------
- Needs Blender 5.2 or newer (5.2 LTS and 5.3 tested).
  需要 Blender 5.2 及以上（已在 5.2 LTS 与 5.3 实测）。
- Windows: the Microsoft Store build of Blender is not
  supported; use the blender.org installer build.
  Windows 应用商店版 Blender 不受支持，请用官网安装版。
- The installer uses Blender's own extension installer;
  nothing is written outside Blender's user folders.
  安装走的是 Blender 官方扩展安装接口，不碰系统目录。
- Source code and full documentation:
  源代码与完整文档见仓库（fork）:
  https://github.com/luoboruodai/Blenda4D
  Original project / 原项目:
  https://github.com/recon007jf/Blenda4D
